TROUBLESHOOTING:
----------------

Problem: Window still closes immediately, never see "SCRIPT STARTING"
Solution: 
   - Try running from Command Prompt manually
   - Check Windows Defender / antivirus logs
   - Try right-click -> "Run as administrator"

Problem: See "Python not found" error
Solution:
   - Install Python 3.9+ from https://www.python.org/
   - During install, CHECK "Add Python to PATH"
   - Then run start.bat again

Problem: See "launcher.py not found" error
Solution:
   - Make sure you're in the correct directory
   - Check that launcher.py exists in the same folder as start.bat

Problem: Packages fail to install
Solution:
   - Check captures/setup_python.log for details
   - May need internet connection
   - May need to update pip manually
