TROUBLESHOOTING (if device still not detected after reset):
------------------------------------------------------------

1. Check the launcher log window for errors

2. Check captures/live_ui_dev.log for messages like:
   - "Session XX started for device CX505" = GOOD
   - "No FTDI D2XX devices detected" = BAD (shouldn't happen now)
   - "Frames: XX, Bytes: XXXX" = GOOD (device is sending data)

3. If you still see "No FTDI D2XX devices detected":
   - Close launcher completely
   - Check Task Manager - kill ALL python.exe processes
   - Run diagnose_device.bat again to verify device
   - Restart launcher

4. If you see "FT_STATUS=3" errors:
   - Another program is using the device
   - Close other FTDI/serial programs
   - Check Task Manager for duplicate python.exe processes
