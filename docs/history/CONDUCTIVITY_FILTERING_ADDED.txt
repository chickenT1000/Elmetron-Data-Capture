PROBLEM SOLVED:
---------------
- Conductivity electrode polarization causing extreme spikes (0 µS/cm to 639 µS/cm)
- Chart autoscaling including outliers, making normal data appear flat
- Median value is ~539 µS/cm, but spikes were distorting the view

SOLUTION IMPLEMENTED:
---------------------
Added IQR (Interquartile Range) outlier detection with MAD (Median Absolute Deviation) backup.

Method:
1. Calculate Q1 (25th percentile) and Q3 (75th percentile)
2. Calculate IQR = Q3 - Q1
3. Define bounds: [Q1 - 2.5×IQR, Q3 + 2.5×IQR]
4. Also calculate median-based bounds using MAD
5. Use the wider bounds (less aggressive filtering)
6. Remove values outside bounds by setting conductivity to null

Parameters:
- IQR multiplier: 2.5 (less aggressive than standard 1.5)
- MAD multiplier: 5.0 (very conservative)
- Minimum data points for filtering: 10
- Keeps the measurement but nulls out only the conductivity outlier

WHAT IT DOES:
-------------
✓ Filters extreme spikes from polarization
✓ Keeps normal measurement variations
✓ Preserves temperature and other parameters
✓ Logs number of outliers removed
✓ Gracefully handles errors (returns unfiltered on failure)
✓ Only filters if there are at least 10 data points

TECHNICAL DETAILS:
------------------
The filter uses two methods and takes the wider bounds:

1. IQR Method:
   - Robust to outliers
   - Works well with skewed distributions
   - Standard statistical method

2. MAD Method:
   - Even more robust than IQR
   - Based on median deviation
   - Backup for extreme cases

By using BOTH and taking wider bounds, we ensure:
- Don't over-filter legitimate variations
- Do remove extreme polarization spikes
- Handle edge cases gracefully

WHAT GETS FILTERED:
-------------------
Typical outliers from polarization:
- Values near 0 µS/cm (electrode not submerged or poor contact)
- Extreme spikes >700 µS/cm (initial polarization)
- Rapid transients when first submerged

What DOESN'T get filtered:
- Normal measurement drift
- Temperature-related variations
- Gradual concentration changes
- Expected measurement noise
